⚡ SANDBOXELS · CONTROLS ⚡

🎮 MOUSE / BRUSH

  • 🖱️ LEFTPlace current element
  • 🖱️ RIGHTErase pixel
  • 🖱️ MIDDLEPick element from world
  • SCROLL ↑↓Increase / decrease brush size
  • [ ] / - +Change brush size (keyboard)
  • SHIFT + dragDraw straight line
  • ALT / OPTHold for alternate tool modes

⏯️ SIMULATION

  • P / SPACEPause / unpause
  • . (period)Step one frame (when paused)
  • RToggle Replace mode (override pixels)
  • C / F2Take screenshot (PNG)
  • FFullscreen mode

🔍 ELEMENT / INFO

  • ESelect element by name (search)
  • I / /Open element info / wiki panel
  • ← → arrowsSwitch element categories
  • ESCClose info / mods / settings
  • MOpen Mod Manager
  • \ (backslash)Open Settings menu

👁️ VIEW MODES

  • 1Default view (element colors)
  • 2Thermal view (temperature gradient)
  • 3Basic view (flat colors)
  • 4Smooth view (blended edges)
  • 0Reset view to default
  • F1Hide / show UI panels

⚙️ ADVANCED

  • TABCycle UI focus / highlight buttons
  • CTRL + Z(No undo, but reset clears world)
  • HOLD SHIFT+ brush = line drawing / extra tool power
  • TPS BUTTONChange ticks per second (speed)
